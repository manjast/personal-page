Build the eval before the build.

/ / / P A T T E R N / / /
; a team builds a RAG system
sample = 20–30 questions
chunk_strategy = "looks right"
prompt_iterate_until_output_reads_well
ship()            ; no measurement
/ / / F I X / / /
eval = build_first()
eval.questions = 50..100 ; from real users, not synthesized
eval.grader = 1..5     ; by the people who will use it
eval.run(after_every_change)

if eval.score_new > eval.score_old:
    keep(change)
else:
    revert(change)
/ / / T H E D A T A / / /
chunking_change     →  score: 3.1  →  3.7   (80 questions)
eval_late_build      →  200+ users in production
revert_window        →  3 weeks  (prompt + chunking + retrieval)

Trace retrieval on every failed answer.

/ / / P A T T E R N / / /
while answer.wrong:
    prompt = rewrite(prompt)
    answer = generate(prompt)
    ; different wrong answer each iteration
/ / / F I X / / /
for every failed_answer:
    log(top_k_chunks, similarity_scores, source_docs)
    ask = "did retrieval find right source?"
    ask = "did the model read it?"
    ; not "why did the model say this"
/ / / T H E D A T A / / /
case_A: chunker split a table across 2 chunks
        fix: 10-line chunker change (keep tables atomic)
        no prompt change. no model change. no embedding change.

case_B: retrieval returned 2022 doc for a 2024 query
        fix: recency-weighted retriever
        no prompt change.

# before the fix:  2–3 weeks  (prompt-engineering rabbit hole)
# after the fix:   2–3 days   (the actual fix)

The 2026 cost discipline.

Frontier model API prices look stable. They are subsidized by VC funding — the post-IPO price is widely expected to be higher than today's. Build the cost discipline now, while the pricing is in your favor.
F.1 · M O D E L
DeepSeek V4-Pro, GLM 5.2, Qwen 3.7 Max, Kimi K2.6, MiniMax M3 ship at 10–30x lower cost than frontier closed-API. Deployable on AWS Bedrock / Azure AI Foundry / Google Vertex / OCI. Deployment flexibility + pricing leverage + the option to self-host on dedicated infrastructure.
F.2 · F O R M A T
Toon cuts input tokens 30–40%, net +12% cost reduction in the best case. GCF goes further but adds reasoning cost. The net is format-dependent: pick per workload.
F.3 · A R C H I T E C T U R E
top-k=20 → top-k=5 + reranker cut cost 4x. Prompt caching reduces repeated-prefix cost 5–10x. The RAG-side lever is the cheapest one — 10-line chunker change, not a 10-week migration.
The era of "as much AI as you can" is over. The era of "as much AI as cost-justified" is here.
